# oishanid.github.io

This is my personal website, where I share who I am, what I'm studying, and what I like to do outside of class. I built it from scratch with plain HTML and CSS (no frameworks or JavaScript) to learn how websites are structured and styled. The site has three main pages: an About Me page with a short intro, an Education page with my coursework, my SIR project, and the other things I'm learning, and an Interests page about music, food, typing, and badminton. I also made a custom blue cursor with an SVG, and I styled the nav bar, cards, and buttons.

## How to use

No setup needed. The site is hosted on GitHub Pages, so you can just open the link above in any browser.

1. Start on the About Me page for a quick intro.
2. Use the nav bar at the top to switch between About Me, Education, and Interests.
3. On the Interests page, use the buttons at the top to jump to music, food, typing, or badminton.

## Project structure

- `index.html`: the About Me page
- `education.html`: coursework, SIR, and other learning
- `interests.html`: music, food, typing, and badminton
- `style.css`: all of the styling for the site
- `images/`: photos used on the site

## Built with

HTML and CSS, hosted on GitHub Pages, with Spotify embeds and icons linked from other sites.
